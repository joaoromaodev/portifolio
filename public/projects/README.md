# Project screenshots

Drop screenshots here and point a project's `image` field at them
(e.g. `/projects/simf.png`) from the admin panel at `/admin`.

- **16:9** works best — the cards crop to that ratio.
- ~1600x900 PNG or JPG is plenty; compress before committing.
- **SIMF and any government screenshot must use fictional or blurred data**
  (CLAUDE.md §8). Never real values, internal DNS/IPs, or people's names.
- Always fill in `imageAlt` too — it's what screen readers announce.
